I'm Khang, a frontend engineer in Ho Chi Minh City (UTC+7). I've built web products since 2018. Today I work on VietnamWorks, one of Vietnam's largest job sites, and Navigos Talent One, its employer recruitment platform.

Production work I'm proud of:

- Built the frontend for AI job posting in Talent One. Employers start a post from a prompt, a JD file or a link, and about 3 in 4 employers who post a job use it each month.
- Designed core parts of Talent One's app shell: typed nested routing and middleware, a typed API client, app-wide state, and English/Vietnamese switching with no reload.
- Own the frontend of the recruitment page builder, a paid add-on for branded hiring pages, with pages live for banks and an international talent program.
- Made the Employer app build 2.4x faster and halved its CI job by reworking the toolchain with TypeScript 7 and Turbopack.
- Implemented the frontend for candidate recommendations and AI screening in the VietnamWorks Employer job-management app, which I've worked on since 2024.

I'm strongest at frontend architecture for large apps that several squads share, shipping AI features to real users, and keeping builds fast. When a product needs it, I take a feature from the UI through to the Node.js API behind it.

I also build AI agent harnesses and use them in real work. In a blind A/B test, the harness I built for my team doubled agent results on tickets that link a PRD or Figma file.

Outside work I build websites for clients, such as [UWANT Vietnam](https://uwant.com.vn) and [FIX Partner](https://fixpartner.co).

### Tools I build

- [React utilities](https://github.com/khanglvm/react) cover shared state, typed translations, browser events, and component helpers. `createContextState` combines selector hooks with reversible Immer updates for optimistic UI. Install with `npm install @khanglvm/react`. [npm](https://www.npmjs.com/package/@khanglvm/react)
- [Relay](https://github.com/khanglvm/relay) gives coding agents a browser board for review. Comments stay attached to visual elements or image areas and return to the agent with your decisions. [npm](https://www.npmjs.com/package/@khanglvm/relay)
- [figma-lens CLI](https://github.com/khanglvm/figma-lens) pairs focused design inspection with an agent skill for checking details and verifying the finished UI. It is my independent tool, not affiliated with Figma. [npm](https://www.npmjs.com/package/figma-lens)
- [Jira CLI](https://github.com/khanglvm/jira-cli) gives people and agents short commands for legacy Jira Server, with dry runs before changes are sent. [npm](https://www.npmjs.com/package/@khanglvm/jira-cli)
- [Outline CLI](https://github.com/khanglvm/outline-cli) finds wiki pages by title or URL, returns focused summaries, and checks revisions before applying patches. [npm](https://www.npmjs.com/package/@khanglvm/outline-cli)

Most of my work uses TypeScript, React, Next.js, Angular, and Node.js. I care about clear module boundaries and the details that make interfaces feel right.
